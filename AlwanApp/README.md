# ألوان البيت (Alwan)

تطبيق آيفون أصلي بلغة **SwiftUI** يعرض ألوان دهان الجدران مرتّبة حسب مناطق المنزل،
ولكل لون يجيب على سؤالين: **حق شنو؟** و **وين استخدمه؟**

## المميزات
- **١٠ مناطق في البيت** — المجلس، الصالة، غرفة الطعام، غرفة النوم، غرفة الأطفال،
  المطبخ، دورة المياه، المدخل والممرات، المكتب، الحوش والسطح.
- **٣٦ لوناً** لكل واحد: الاسم والرمز وكود `HEX`، الأثر النفسي، الجدار المناسب بالضبط،
  سلوك اللون مع الإضاءة، نوع الدهان الموصى به (مطفي / ساتان / نصف لامع)، وألوان منسجمة معه.
- **معاينة الغرفة** — رسم مبسّط للجدار والأثاث بلون المعاينة قبل ما تشتري.
- **خطة البيت** — تعتمد لوناً لكل غرفة، ويولّد لك **قائمة شراء** جاهزة للمشاركة مع محل الدهان.
- **المفضلة** وبحث وتصفية حسب عائلة اللون.
- واجهة عربية بالكامل باتجاه من اليمين لليسار، وتدعم الوضع الليلي تلقائياً.

## التشغيل
يحتاج **macOS + Xcode 16** فأعلى (هدف النشر iOS 18).

```bash
open AlwanApp/Alwan.xcodeproj
```

ثم اختر جهازك أو المحاكي واضغط ▶︎ (أو `⌘R`).

لتشغيله على آيفونك شخصياً: من **Signing & Capabilities** اختر حسابك في *Team*،
وغيّر `PRODUCT_BUNDLE_IDENTIFIER` من `com.kkalida.alwan` إلى معرّف خاص بك.
حساب Apple المجاني يكفي للتجربة على جهازك (تنتهي صلاحية التثبيت كل ٧ أيام)،
أما النشر على App Store فيحتاج اشتراك Apple Developer.

## البنية
```
AlwanApp/
├─ Alwan.xcodeproj
└─ Alwan/
   ├─ AlwanApp.swift        نقطة الدخول
   ├─ Models/               Room.swift · PaintColor.swift
   ├─ Data/ColorCatalog.swift   كل الألوان ونصوصها
   ├─ Store/FavoritesStore.swift  الحفظ في UserDefaults
   └─ Views/                الواجهات
```

لإضافة لون جديد: أضف عنصراً واحداً في `ColorCatalog.all` — لا يحتاج أي تعديل آخر.
