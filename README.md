# نظام تسجيل الحضور والغياب

تطبيق ويب بسيط لتسجيل حضور وغياب الطلاب، بواجهة عربية (RTL) ومناسبة للجوال.
مبني بـ HTML و CSS و JavaScript فقط، ويحفظ البيانات في متصفحك عبر `localStorage`.

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح — لا يحتاج أي خادم أو تثبيت.

## الصفحات
| الملف | الوظيفة |
| --- | --- |
| `index.html` | إضافة الطلاب وحذفهم وعرض قائمتهم |
| `attendance.html` | تسجيل الحضور اليومي حسب التاريخ (مع أزرار «الكل حاضر/غائب») |
| `history.html` | عرض السجلات حسب التاريخ مع تصفية بالاسم أو التاريخ أو الحالة |
| `stats.html` | نسبة الحضور وعدد الغيابات لكل طالب + ملخص عام وحذف البيانات |
| `app.js` | التخزين (localStorage) والدوال المشتركة |
| `style.css` | التنسيقات |

## ملاحظات
- البيانات محفوظة محلياً في المتصفح فقط، ولا تُرسل إلى أي خادم.
- حذف طالب يحذف أيضاً كل سجلات حضوره.
