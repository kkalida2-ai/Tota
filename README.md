# دفتر الحضور

تطبيق ويب عربي (RTL) لتسجيل حضور وغياب الطلاب. ملف واحد، بدون أي إطار عمل أو خادم،
ويحفظ البيانات في متصفح المستخدم عبر `localStorage`.

## المميزات
- **فصول متعددة** — لكل فصل طلابه وسجله وإحصائياته منفصلة.
- **إدخال دفعة أسماء** — الصق القائمة كل اسم في سطر، مع تجاهل المكرر.
- **تعديل وحذف** الطلاب والفصول عبر نوافذ داخل الصفحة.
- **تسجيل يومي** حسب التاريخ، مع زر «تعليم الكل حاضر» ومسح اليوم.
- **سجل** يُصفّى بالتاريخ أو اسم الطالب أو الحالة.
- **إحصائيات** — نسبة الحضور وعدد الغيابات لكل طالب، وملخص عام للفصل.
- **نسخة احتياطية** نصية لنقل البيانات بين الأجهزة.
- وضع ليلي تلقائي، وتصميم مناسب للجوال.

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرة — لا يحتاج تثبيت أو خادم.

## النشر على GitHub Pages
من صفحة المستودع: **Settings** ← **Pages** ← في **Source** اختر *Deploy from a branch*،
ثم الفرع `claude/remote-control-docs-ju5ijf` والمجلد `/ (root)` ← **Save**.
بعد دقيقة تقريباً يصبح الموقع على:

```
https://kkalida2-ai.github.io/Tota/
```

## ملاحظات
- البيانات محفوظة في متصفح الجهاز فقط ولا تُرسل إلى أي خادم، فهي لا تتزامن بين الأجهزة.
  استخدم تبويب «النسخة الاحتياطية» لنقلها.
- مسح بيانات الموقع من المتصفح يحذف السجلات، لذا خذ نسخة احتياطية بعد إدخال الفصول.
